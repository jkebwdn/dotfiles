# tfm-tui: future side-by-side evaluation only

Inspected 2026-11-05: [upstream repository](https://github.com/clarkarch/tfm-tui).
This is a research note, not an installation or migration plan.

The beta offers dual panes/tabs, grid/list browsing, thumbnails/previews, network
locations, archives, bulk rename, undo/redo, embedded terminal, plugins and themes.
Its transparent-background support could inherit Ghostty's accepted alpha/blur path.
Upstream still recommends backups for irreplaceable data. Its beta maturity and broad
file-operation surface warrant testing on disposable copies before ordinary use.

A later approved side install could launch tfm explicitly inside Ghostty against a
fixture directory, with a separate configuration and no default-file-manager setup.
Compare GVFS access, keyboard/mouse behavior, thumbnails and recoverability before
considering any migration. No installation, MIME/folder association, Thunar launcher,
PRIME configuration or default application changed in the Thunar/Hub phase.
